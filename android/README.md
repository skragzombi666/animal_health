# Animal Health Android

Standalone Android alpha app for Animal Health. It stores its data locally on the Android device and does not require Home Assistant.

## 0.9.0-alpha.1

The first alpha focuses on practical field testing:

- local animal master data,
- weight recording,
- compact multi-medication recording,
- chronological health timeline grouped by day,
- repeat/copy/correct medication administrations,
- simple reminders/tasks,
- user-defined medication presets,
- local JSON export/share.

The APK is currently debug-signed for direct sideload testing. It is not a Google Play production build.
